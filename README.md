# FastSpeech 2 for English and Telugu

IIIT Hyderabad RA assignment: FastSpeech 2 text-to-speech models trained from scratch on English (Svarah) and Telugu (IndicTTS).

Everything requested by the assignment is in [`project/`](project/): code, configs, checkpoints, results and the report. Start with [`project/README.md`](project/README.md).

Supporting code: `fs2ra/` (shared project code), `scripts/` (data download, splits and helpers), `notebooks/` (Google Colab training and alignment), `patches/` (changes to the reference FastSpeech 2 code) and `tests/`.
